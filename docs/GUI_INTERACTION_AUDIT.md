# GUI 交互与样式验收

日期：2026-10-19。分支：`codex/gui-tests`。环境：macOS ARM64、Wails 2.10.1、Go 1.25.5、原生 WKWebView。下面区分原生实际操作、自动化边界测试和未执行的验收，避免把组件断言当成像素结果。

## 公司配置与网页基线

- 使用用户现有“公司mac”配置；原生 Profiles 的测试连接返回成功，包含现有跳板认证链。未复制公司密码到仓库或 fixture。
- 在浏览器权限拒绝发生前，通过现有 HTTP 代理请求用户指定 HTTPS 地址，得到 HTTP 200、`text/html`、页面标题 `IDE`。这是 HTML 入口可达证据，不能证明浏览器 JavaScript、子资源或业务操作可用。
- 浏览器首次访问被拒绝。用户再次明确授权后重试，仍被保存的站点权限或受管策略拒绝；没有再通过其他浏览器、终端 HTTP 或代理绕过这个限制。
- 原计划的隔离 app bundle 被 Computer Use 权限拒绝，已停止该测试进程。后续使用已授权的 GoTun 原生应用；真实配置只做连接/启停，增删改使用本轮创建的临时配置，最后删除。
- TUN 提权确认弹窗打开后取消；没有申请管理员权限或创建真实 TUN/系统路由。

## 可重复的真实 HTTPS 测试

`internal/service/live_integration_test.go` 提供显式 opt-in：`GOTUN_LIVE_CONFIG`（已有配置 JSON 路径）、`GOTUN_LIVE_PROFILE`（精确 ID）、`GOTUN_LIVE_URL`（目标 HTTPS URL）；可选 `GOTUN_LIVE_EXPECTED_TITLE`，默认 `IDE`。三个必需项全空时跳过，部分配置或连接失败会失败。

测试保留认证/跳板链，用临时 loopback HTTP 代理走 SSH CONNECT 和 TLS；不更改已保存配置、系统代理或路由。验证证书、200、HTML 类型、大小限制和标题；只允许同 origin HTTPS 重定向，移除 Referer。失败消息不输出授权 URL、凭据或 HTML 正文。它不执行网页 JavaScript。

本轮自动运行的是本地 SSH/TLS fixture（含非法证书、错误状态/类型/标题、重定向隐私回归）。由于公司站点浏览器策略拒绝，真实 opt-in 用例没有被当成绕过浏览器拒绝的方式执行。
